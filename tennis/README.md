# Архив live тенниса

Активный контур и команда `live теннис` перенесены в `Dzammbo/jarvis-intuition`, исполняемый workflow - в `Dzammbo/Intuition_collector`.

Здесь сохранена только неизменяемая история переноса: прежние снимки, реестр и результаты. Исходная книга сохранена в `Live теннис/Live теннис.xlsx`. Не запускать теннис из Scaner и не добавлять сюда новые записи.
