# Памятка по ТМ 1,5 жёлтых карточек в первом тайме

Версия: 15.10.2026

## 1. Назначение

Это отдельное исследовательское направление, не часть алгоритма live ТБ.

Целевой рынок: **ТМ 1,5 жёлтых карточек в первом тайме**, включая карточки в компенсированное время до перерыва.

Рабочий режим:

1. Дзам присылает конкретный матч, по которому букмекер предлагает рынок ЖК.
2. Джарвис восстанавливает актуальный контекст из `main`, читает эту памятку и проверяет свежие данные по матчу.
3. Матч оценивается по спортивным признакам, подтверждённым карманам, составу участников, судье, турнирному контексту и цене.
4. Ответ: **ПОДХОДИТ / ПОГРАНИЧНО / НЕ ПОДХОДИТ**, аргументы за и против, достаточность данных и минимально оправданный коэффициент, если его можно обоснованно оценить.

Короткая команда: **`ЖК: <турнир>, <команда 1> - <команда 2>, ТМ 1,5 за <коэффициент>`**. Скриншот линии можно приложить вместо текста.

## 2. Критически важное ограничение

Букмекер предлагает рынок ЖК выборочно. Есть риск, что рынок отсутствует именно в наиболее низовых лигах и матчах, а доступная выборка линий смещена к более карточным событиям.

Поэтому:

- историческая частота турнира не переносится автоматически на матчи, где букмекер открыл линию;
- наличие рынка не является положительным признаком;
- окончательное решение принимается только по конкретному матчу;
- при коэффициенте 1,50 точка безубыточности равна 66,67%;
- для коэффициента `K` точка безубыточности равна `1 / K`;
- проценты ниже рассчитаны без исторических коэффициентов. Условный ROI при 1,50 служит только для сравнения.

## 3. Методика исследования

Источник: реальные ответы BetsAPI Events API.

Основной массив: последние 500 завершённых матчей каждого турнира. Для ЛЧ разрешено 495 из 500 матчей после проверки качества данных. Карточки считались по таймлайну до маркера окончания первого тайма, включая 45+.

Для поиска закономерностей использовалось разделение старой и новой половин выборки. Карманы, найденные на старой части и проверенные на новой, имеют больший вес. Командные показатели по всей выборке считаются описательными и требуют свежей проверки.

## 5. Основные рабочие закономерности

### 5.1. Лига чемпионов

Главная закономерность: **ровно один участник из группы наиболее регулярно играющих грандов**.

Группа Top-12 исследования: PSG, Real Madrid, Bayern Munich, Arsenal, Borussia Dortmund, Atletico Madrid, Barcelona, Inter Milan, Manchester City, PSV, Benfica, Liverpool.

- Ровно один клуб Top-12: 168 из 231, 72,7%.
- На более свежей половине: 83 из 109, 76,1%.
- Ни одного клуба Top-12: 107 из 179, 59,8%.
- Оба клуба Top-12 на свежей половине: 32 из 51, 62,7%. Матч двух грандов не является автоматическим плюсом.
- Клубы Top-12 в среднем получали 0,55 собственной ЖК в первом тайме против 0,65 у остальных.

## 6. Иерархия признаков для конкретного матча

Признаки не являются жёстким фильтром. Их вес:

1. Проверочный карман турнира с достаточной выборкой.
2. Совпадение обеих команд с устойчивой низовой группой.
3. Собственная частота ЖК первого тайма каждой команды на свежей и длинной дистанции.
4. Судья, только если эффект подтверждён именно в этой лиге.
5. Сила и асимметрия матча: отдельные лиги поддерживают сильного хозяина, но не сильного гостя.
6. Турнирный контекст: дерби, ответный матч, вылет, принципиальный конфликт, высокая цена результата повышают риск.
7. Цена. Даже хороший спортивный сценарий не подходит при коэффициенте ниже обоснованной границы.

Несколько коррелирующих признаков нельзя считать независимыми и перемножать. Команда из низовой группы, низкое ожидаемое число ЖК и высокий исторический процент ТМ могут описывать один и тот же эффект.

## 7. Формат разбора присланного матча

```text
Матч:
Турнир и стадия:
Рынок и коэффициент:
Доступность и качество данных:

Факты:
- команды;
- собственные ЖК первого тайма;
- общий матчевый профиль;
- судья;
- сила команд и контекст;
- совпадение с проверенными карманами.

Риски:
- отрицательные признаки;
- малая или устаревшая выборка;
- селекция букмекером;
- цена.

Заключение: ПОДХОДИТ / ПОГРАНИЧНО / НЕ ПОДХОДИТ.
Минимально оправданный коэффициент:
Уверенность:
```

Если коэффициент или точная формулировка рынка не указаны, можно оценить только спортивную пригодность. Финансовое заключение без цены не давать.

## 8. Что нужно обновлять со временем

- Не переносить командный показатель автоматически после смены тренера, состава, дивизиона или выраженного изменения режима.
- Для конкретного матча проверять свежий отрезок и сопоставлять его с длинной выборкой.
- Новую закономерность добавлять в памятку только после проверки на независимой или более свежей части данных.
- Любой новый прогон фиксировать с датой, размером выборки, точным определением рынка и источником данных.
