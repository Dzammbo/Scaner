# Два независимых сбора по команде Live

Согласовано 18.10.2026. Один свежий полный запрос через .github/live-request.json на main автоматически запускает два самостоятельных workflow:

1. Manual BetsAPI live football snapshot — рабочий отбор main. Правила допуска, ранжирование, формат и реестры прежние. Только его короткий финальный список выводится пользователю.
2. Independent experimental Live capture — код и данные ветки research/selection-lab-20261018. Собственные inplay, тренды, профили, рынки, журналы, контрольные матчи и исходы. Результат исследовательский, не пользовательская публикация.

Не ждать экспериментальный workflow перед выдачей рабочего списка. При чтении workflow runs выбирать именно рабочий workflow по имени/файлу betsapi-live-football-snapshot.yml; LAB_CAPTURE_STATUS и экспериментальные artifacts не являются рабочим Live. Ошибка второго workflow не меняет рабочую выдачу. Оба сохраняют SHA исходного запроса для последующего сопоставления. Основной и экспериментальный журналы никогда не объединяются для исключения матчей.

Эксперимент: глубокие данные до 60 кандидатов, до 30 запросов рынков для сильных и контрольных вариантов; 4 параллельных обращения, максимум 240 запросов за проход с резервом 200 известных оставшихся запросов для основного контура. На последующих Live после нового сбора проверяются до 20 прежних экспериментальных исходов, в пределах того же бюджета. Запросы при нехватке бюджета остаются неизвестными, а снимок помечается частичным. Отсутствующая цена точного округлённого тотала не выдумывается.

Второй workflow запускается только полным Live через канонический push запроса. Refresh не запускает новый экспериментальный отбор. Дополнительно действует отдельный фоновый сбор обоих контуров каждые 10 минут до ручной остановки, без чата и без записи в ручные публикации. Его настройки описаны в docs/live-background.md. Ручной workflow_dispatch старого рабочего workflow сам по себе не запускает вторую задачу: для обоих использовать канонический запрос Live.

Логика и данные изолированы; поставщик API, подписка и GitHub общие. Общую очередь и лимит невозможно объявить независимыми. Разные времена снимков и разные прошлые исключения учитывать при сравнении эффекта правил.

Технические детали, параметры, ограничения и тесты: research/selection-lab-20261018/Сбор.md в исследовательской ветке. Новый сбор включён для следующей команды Live; при настройке сетевой Live не запускался.
