# Проверка качества основного отбора
Версия remaining-goals-quality-v1-20261024. Согласовано 24.10.2026.

Основная серия shared-top5-forward-20261022-v2 сохраняется контрольной. Новая модель оценивает те же первые входы общей пятёрки после её действующих исключений. Квота не пополняется. Это проверка качества допуска на общей базе, а не замена спортивного ранжирования и не новая подборка карманов.

Активация - первый успешный фоновый проход после создания замороженной модели. Все ранее наблюдавшиеся к этому проходу ID и ID обучающих блоков исключаются. Один исходный вход на матч. Неизвестная цена не дополняется позже; отсутствие обязательной статистики фиксируется, не заменяется нулями. Повторные исследовательские наблюдения и прежние серии сохраняются.

Модель оставшихся голов: регуляризованная пуассоновская регрессия, оставшееся время как экспозиция; счёт, разница счёта, створы, завершения последних полных пяти минут, опасные атаки, сопоставимый исторический профиль, удаления. У неизвестных необязательных полей отдельные индикаторы. Одна модель фиксируется на весь эксперимент; автоматического переобучения нет.

Источник обучения заморожен: research/all-entry-audit/2026-10-24/40067569187-1/entry-points.json.gz, SHA256 b5a17fb390b11bb34562335a89b360f005631f0eebcf8ce507bff4ed02ed58bd.
Первый подходящий точный вход v8 на матч, 8-60, вход 08-24 МСК, профиль <1.1. Последовательные блоки 60/20/20 по времени первого входа, без пересечения ID. Для обучения исход должен быть подтверждён до начала калибровочного блока, для калибровки - до начала проверочного блока. Неизвестное время подтверждения исключает строку из обучения. Порог минимальных объёмов 150/30/50 после очистки. Проверочный блок не используется при обучении или настройке порога.

Калибровка: отношение фактически оставшихся голов к прогнозу на отдельном блоке, множитель ограничен 0.5-2.0. Проверяются средний прогноз и логарифмическая ошибка распределения на следующем отдельном блоке. Историческая проверка не называется новым будущим результатом.

На каждом будущем входе сохраняются полное распределение исходов азиатского тотала, прогноз оставшихся голов, ожидаемый чистый результат, исходная линия и цена, старая модель на той же точке, версия и SHA256 модели. Половинные выигрыши, половинные проигрыши и возвраты учитываются точно. Новый допуск: ожидаемый чистый результат >=0.05 на условную единицу; это проверяемая оценка модели, не гарантированное преимущество.

Сравнение:
- Контроль использует все исходные ценовые возможности общей базы; кандидат принимает подмножество на той же минуте и цене.
- Для каждого варианта показываются N, фактический ROI, чистый результат и ROI без трёх лучших; пропуск кандидата даёт нулевое вложение, не считается завершённым входом в его ROI.
- Дополнительно сравнивается чистый результат на одну общую возможность, с парной разницей. Доверительный интервал этой разницы рассчитывается блоками по дням, не отдельными повторными наблюдениями.
- Прогноз и факт оставшихся голов, пуассоновская ошибка, Brier полного выигрыша новой и прежней модели на одинаковых матчах.
- Диапазоны ожидаемого результата: <-0.05, -0.05-0, 0-0.05, 0.05-0.10, 0.10-0.20, >=0.20. Для сравнения порядка качества минимум 50 завершённых матчей в диапазоне.

Предварительно фиксированные критерии достаточности свидетельств: минимум 500 общих завершённых ценовых входов, 7 разных дней входа, 100 принятых кандидатом; положительные ROI кандидата и ROI без топ-3; ошибка среднего оставшихся голов <=10%; доступность старой модели минимум на 80% общих расчётов; меньшие логарифмическая ошибка и Brier на совпадающих матчах; рост фактического результата в достаточно наполненных диапазонах качества; положительная нижняя граница 95% дневного блочного интервала парной разницы. Ошибки обязательных признаков или пропущенные проходы сравнения запрещают готовность свидетельств.

Автоматической замены основной серии нет, включая случай прохождения критериев. Ошибка модуля не прерывает основной сбор, но видна в квитанции и отчёте; такой промежуток нельзя выдавать за полное сравнение.

В «статистике» после основной серии отдельно выводить «Проверка нового отбора»: начало, общий N, N кандидата, два ROI, чистый результат на общую возможность, калибровка и статус достаточности данных. Не смешивать с основной серией и не обнулять её. Пока критерии не выполнены, писать «проверка продолжается».
