# Широкая исследовательская база

Согласовано 18.10.2026. Вместо сбора только подтверждений старых гипотез формируется проспективная база разных фаз, счетов и турниров. 1000–1500 уникальных матчей — ориентир, не лимит, не квота и не причина остановки. Интервал 10 минут до ручной остановки сохраняется.

Исследовательский контур сохраняет весь неповторяющийся по ID реальный футбольный inplay-пул и сырую выдачу поставщика. Нет фильтра наблюдения по минутам 8–60, текущему счёту, «силе» и достаточности истории. Виртуальные события исключаются из аналитической вселенной.

На каждом проходе до 60 НОВЫХ глубоких входов, распределённых по минутным диапазонам и количеству голов, с воспроизводимым случайным выбором внутри ячеек и сохранённой вероятностью включения. Эти 60 — исследовательская выборка, не прогнозы. Прежняя метка силы — только диагностический признак.

Повторно в глубокую выборку не брать ID, уже вошедшие в неё в исследовательском контуре, включая его ручной/фоновый источник и прежние снимки. Просто наблюдавшиеся, но не попавшие в глубокую выборку, остаются кандидатами следующих проходов. Сырые повторные board-наблюдения и расчёт исхода продолжаются; независимое N по ID не увеличивается.

Для всех наблюдавшихся ID ведётся очередь конечных исходов: до 20 пакетных запросов по 10 ID в проход. Глубокие данные: сырой stats_trend и derived-признаки, профиль/N до kickoff, реально доступные рынки FT и первого тайма. Результат event/view хранится отдельно и не является признаком, известным на раннем live-снимке.

Бюджет experimental остаётся 240 API-запросов, primary 120, резерв 200. При неполных данных сохраняются неизвестность и частичный статус. Цены всех матчей не гарантируются. Прогресс по уникальным ID, трендам, закрытиям и точным ценам хранится раздельно; снимки не складываются в независимое N.

Рабочий main Live по-прежнему 0–5 сильных, прежний допуск/ранжирование/короткий формат. Его журнал публикаций не получает исследовательские выборы, Excel не меняется. Детали новой версии: research/selection-lab-20261018/Наблюдения.md в исследовательской ветке. Старые и новые версии данных различать при анализе.
