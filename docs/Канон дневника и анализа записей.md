# Канон дневника и анализа записей

## Канонический файл

`Дневник исходов/Дневник исходов.xlsx`

Листы книги:

- «Сводка»;
- «Реестр»;
- «Исходы»;
- «Правила»;
- «Анализ».

Структуру книги, формулы, оформление и нумерацию сохранять. Менять только данные, необходимые для конкретного поручения.

## Добавление записи

Перед внесением проверить:

1. следующий номер записи;
2. дату;
3. вид спорта;
4. турнир;
5. матч;
6. точный рынок и линию;
7. коэффициент;
8. сумму;
9. тип Live или прематч;
10. статус;
11. специальные условия расчёта.

Если на скриншоте несколько событий, каждое заносить отдельно, если пользователь явно не указал купон или иной объединённый формат.

## Результаты

- Результат брать из проверяемого источника.
- Не закрывать запись по неполному или неоднозначному счёту.
- Возврат, отмену, перенос и специальные правила рынка учитывать отдельно.
- Исходные коэффициент, сумма, линия и тип записи задним числом не менять.
- Для бонусной записи отдельно учитывать невозвращаемую часть бонуса по фактическим правилам.
- После обновления проверять формулы и связанные итоги.

## Анализ

Основные обязательные показатели:

- число записей;
- рассчитанные, открытые, возвраты и отменённые;
- победы и поражения;
- общая сумма;
- финансовый результат;
- доходность;
- средний коэффициент;
- результат по Live и прематчу;
- результат по видам спорта, турнирам, рынкам и диапазонам коэффициентов;
- динамика по времени.

Для каждого разреза обязательно показывать размер выборки. Малые выборки обозначать как предварительные.

Не складывать пересекающиеся разрезы как независимые результаты. Не менять правила отбора задним числом ради улучшения статистики.

## Синхронизация

После изменения дневника:

1. сохранить книгу под тем же именем;
2. обновить файл в `main`;
3. синхронизировать рабочую копию в ChatGPT Library;
4. проверить совпадение версии, размера и контрольных итогов;
5. только после этого сообщать об успешном обновлении.
