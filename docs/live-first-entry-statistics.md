# Статистика: один вход на матч

Согласовано 20.10.2026. Версия first-qualified-priced-per-model-event-v1-20261020. Этот документ имеет приоритет над прежним выводом ROI всех повторных входов.

Все наблюдения, точные основные линии и цены, минуты, счёт, признаки, версии моделей и ссылки на снимки сохраняются. Сбор не ограничивается первыми входами.

Основной расчёт каждой модели, пяти карманов и десяти сочетаний использует первый по времени сохранённый подходящий вход с точной основной линией и ценой, максимум один на пару модель + ID матча. Ранг не ограничен пятёркой. Выбор выполняется до расчёта исходов: поздний выигрыш не заменяет ранний проигрыш, возврат, конфликт или нерассчитанную запись. При одинаковом времени применяется стабильный порядок snapshot_id, entry_id.

Источник новой серии: сохранённые model_entries версии all-qualified-model-entries-v2-20261020 с момента её запуска 20 октября. Это пересчёт имеющихся записей по новой методике, а не новый независимый тест на будущих данных. Недостающие прошлые наблюдения не восстанавливаются. Прежние первые выборы с квотой Top5 и более ранние версии остаются отдельным архивом, без слияния знаменателей.

В entry_progress.first_entry_progress сохраняются выбранные entry_id, версия и показатели по моделям. В pocket_audit основной раздел first_entries; current означает архив первых выборов с квотой Top5. repeated и repeated_top5 доступны как диагностические данные, их ROI не выводится в обычной команде «статистика».

## Формат команды «статистика»

Время среза по Москве. Всего уникальных матчей, завершённых, завершённых с точной ценой. Отдельно количество модельных наблюдений и охваченных ими уникальных матчей: модельные записи не равны независимым матчам и количеству сырых снимков.

Основная серия: стандартный v8, исследовательские отборы, пять карманов, десять сочетаний. Каждая строка: «Название: X уникальных матчей, ROI ±Y% (N=Z)». N включает только завершённые валидные расчёты с точной ценой, включая возвраты. При N=0 ROI отсутствует. Указывать начало серии; архив Top5 выводить отдельным подписанным блоком по запросу. Все группы пересекаются и не складываются в портфель.

Окна входа задаются заранее отдельными вариантами. Сначала применить условия окна к наблюдениям, затем выбрать первый вход на матч внутри окна. Нельзя выбирать лучший вход по итоговому результату. first_entries поддерживает predicate для такого исследования; новые окна автоматически не запускаются. Найденные на истории правила отдельно проверяются на будущих данных.

Для общего портфеля нескольких моделей требуется заранее определённый приоритет единственного входа на матч. До его согласования общий ROI перекрывающихся моделей не рассчитывать.
