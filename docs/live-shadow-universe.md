# Полный теневой учёт футбольного Live

Версия full-board-shadow-v1-20261024. Отдельное исследование без изменения основной пятёрки, модели качества и двадцати карманов.

Каждый успешный общий проход уже сохраняет снимок всех доступных невиртуальных матчей, попытки получить точную основную линию и исходы всех наблюдаемых ID. Новый журнал сохраняет первую доступную точную линию и цену на матче в окне 5–89 минут с известным счётом, до допуска strong v8. Если котировки нет, это явно учитывается в покрытии; котировка более позднего момента не подставляется задним числом. Для каждого матча сохраняется одна первая исполнимая точка и отдельно все последующие доступные котировки на очередных пятиминутных снимках. Каждая точка содержит время наблюдения цены, линию, спортивное решение, свежие признаки при их наличии и источник снимка. Повторные точки одного матча нельзя считать независимыми матчами. События с уже подтверждённым окончанием не добавляются в новую серию.

Статусы: strong_v8, rejected_strong_v8, insufficient_sports_data, not_deep_evaluated. Последний означает, что из-за бюджета API или маршрутизации не было глубокой оценки, а не спортивный отказ. При расчёте результата используются только подтверждённые исходы и исходные цены. Матчи без цены учитываются в наблюдаемой популяции и покрытии, но ROI для них не существует. Данные до активации не переносятся в новую серию. Группы являются наблюдательными и не доказывают причинный эффект фильтров.

Квитанции: research/live-background/experimental/shadow-receipts/<дата>/<проход>.json.gz. Результаты: поле shadow_universe файла research/live-results-refresh/<дата>/<проход>.json. Ошибки прохода и отсутствующий журнал сохраняются явной квитанцией ошибки. Исходные снимки и результаты остаются в прежних журналах. Частота и лимит API не меняются, поэтому недоступные котировки и неполученные глубокие признаки не считаются проверенными.

С 24 октября политика запросов котировок направляет бюджет на матчи с известным счётом в окне 5–89 минут. Строки вне окна остаются в полном сыром снимке и очереди исходов; для них котировка не запрашивается. Это не отсекает отвергнутые по strong v8 матчи внутри окна.
