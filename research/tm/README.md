# Отдельный контур ТМ

Согласован 16.10.2026. Статус: исследование истории, не готовая live-стратегия.

- `live` и `live ТБ` остаются прежним контуром ТБ. `live ТМ` - отдельная команда; до валидации правил не выдаёт исследовательские гипотезы за готовые сигналы.
- Код, запросы, исходные данные, отчёты, версии и реестр ТМ находятся только в `research/tm/`. Workflow `tm-research.yml` отдельный, только ручной запрос, без расписания.
- Нет импорта кода ТМ из ТБ и изменений рабочих скриптов, фильтров, workflow, дневников или исключений ТБ. Появление матча в одном контуре не исключает его из другого. Общий API-лимит требует резерва для live; исследование прекращает новые запросы при остатке <=800.
- Исторические данные выбираются из широкого списка завершённых матчей, не из Top-10 ТБ. Первый ограниченный этап: английская Премьер-лига и испанская Ла Лига, идентичность проверяется по ответам API.
- Разведка гипотез допускает ограниченный зафиксированный перебор признаков и их сочетаний. Временные части: 60% поиск, 20% выбор финальных гипотез, 20% однократная проверка; матчи не разделять между частями. Любое изменение после просмотра проверки требует нового будущего периода.
- Сравнение при одинаковых лиге, минуте и текущем счёте; редкие сочетания не объявлять рабочими. Учитывать число перебранных гипотез, зависимые наблюдения и доверительные интервалы.
- Голевой профиль обязателен в будущей модели: до 20 предыдущих матчей команды до старта текущего матча, забитые/пропущенные, 0–1/2/3+, домашний/выездной срез, HT/второй тайм при наличии, база той же лиги. Неизвестное не равно нулю. Профиль рассчитывается только из предшествующих матчей, не из сегодняшней истории применительно к прошлому.
- Цель: распределение дополнительных голов. Финансовые результаты только по реально сохранённым на момент сигнала линии и цене, с возвратами и четвертными исходами. Без таких цен только спортивная проверка и расчёт пороговой цены, не заявление о прибыльности.
- Нули при плохом покрытии не являются признаком ТМ. Полнота поминутной истории, минуты голов и конечный счёт проверяются отдельно.
