# Протокол исторического поиска ТМ

Версия tm-research-v1, зафиксирована до расчёта отложенной проверки.

Популяция: по 500 последних завершённых матчей АПЛ и действующей Ла Лиги, плюс до 200 более ранних матчей лиги для прогрева истории. Не использовать выборку выбранных ТБ. Любой пропуск API сохраняется и входит в отчёт покрытия.

Единица наблюдения: матч на фиксированной минуте 30, 40, 60, 70 или 80. Для одной гипотезы на одной минуте каждый матч учитывается один раз. Исследуемые исходы: не более одного или не более двух дополнительных голов до конца основного времени. Разные минуты одного матча нельзя суммировать как независимые прогнозы.

Сначала 60% матчей каждой лиги по времени для поиска, затем 20% для выбора максимум пяти гипотез и последние 20% для однократной проверки. Матчи с одинаковым временем начала не разделяются. Из 18 заранее заданных булевых признаков перебираются одиночные и парные сочетания: максимум 1710 комбинаций с минутами и двумя исходами. Пороговые значения зафиксированы в analyze.py, не подгонять после просмотра проверки. В поиск допускаются >=60 совпадений на обучении и >=40 сопоставимых контролей; на валидации >=20 и >=15 соответственно. Эти числа - требования анализа, не новые live-фильтры.

Контроль: та же лига, фиксированная минута и точный текущий счёт; в каждой страте >=5 контрольных матчей. Сравнение взвешивается числом выбранных матчей. Пять финальных гипотез проверяются перестановочным тестом внутри страт (4999 перестановок, фиксированный seed) с поправкой Холма. Спортивный эффект может считаться прошедшим этот этап только при скорректированном p<=0.05 и >=50 сопоставимых тестовых матчах; это не доказательство прибыльности. Интервалы Уилсона для долей - описательные, без одновременной поправки.

Голевой профиль строится из предшествующих матчей той же лиги: до 20 на команду и 50 на лигу. Трёхчасовой зазор после старта предшествующего матча предотвращает попадание ещё не завершённого обычного матча. Это не полный межтурнирный профиль. Домашний/выездной, забитые/пропущенные, частоты и второй тайм хранятся отдельно. Совпадения матчей и исправления счёта проверяются.

Поминутные признаки ограничены одновременно игровым временем и created_at, обновления после точки решения не используются. Конечные значения рядов сверяются с итоговой статистикой только как проверка качества покрытия, не как признаки. Сброс счётчика не является снижением угрозы. Историческая доступность исправленного ряда не доказывает своевременность первоначальной live-подачи.

Цена: только основная линия Events bet365 1_3, последнее наблюдение не позже точки решения, возраст <=120 секунд, совпадающий счёт, корректная линия с шагом 0.25. Устаревшие/противоречивые котировки исключаются только из финансового знаменателя. Считается условный результат равной единицей с половинными выигрышами/проигрышами и возвратами. Доступность исполнения в Олимпе не подтверждена. Оборот и ROI нельзя переносить на матчи без исторических цен.

Критерий поиска - спортивный эффект относительно сопоставимых матчей, не максимальный ROI. Положительные значения на малой выборке называются кандидатами. Финансовое преимущество требует отдельной проверки на новых данных и реальной доступности цены. Никакие правила не активируются в live автоматически по окончании исследования.

## Поправка качества v1.1

Первый расчёт сохранён как предварительный. Обнаружены две методические проблемы: (1) исключение целого матча по исправлению счётчика голов после исследуемой минуты использовало будущее для допуска; (2) отдельные календарные границы двух лиг частично перекрывались между валидацией и проверкой. Исправлено: общие строгие временные границы для всех матчей; исключается только точка с исправлением счёта в предшествующие 20 минут, известным на тот момент. Последующие исправления не убирают более ранние точки. Четыре ряда с несовпадением итоговых голов остаются непригодными; у ещё одного матча нет нужного временного покрытия.

Численные пороги признаков, список сочетаний и критерий поиска не менялись ради результата. Однако поздняя часть уже просматривалась, поэтому повторный расчёт считается разведочным, а не новой независимой проверкой. Никакое положительное значение ROI из этой работы не активирует модель. Для подтверждения нужна новая выборка, не использованная в поиске. Актуальные границы по timestamps проверены audit.py.
